# Kumon Vila Flórida — landing page

Landing page estática e responsiva em HTML5, CSS3 e JavaScript puro. Abra `index.html` diretamente no navegador.

## Antes de publicar

1. Edite o objeto `UNIT` no início de `js/script.js` com telefone, WhatsApp, endereço, horários, Instagram e Maps.
2. Substitua os placeholders visíveis no `index.html`.
3. Troque depoimentos e números provisórios apenas por dados reais e autorizados.
4. Substitua o bloco de mapa pelo `iframe` de incorporação fornecido pelo Google Maps.
5. A logo usa temporariamente um arquivo remoto do site oficial do Kumon, pois nenhum arquivo de logo estava presente na pasta recebida. Para produção, salve a logo oficial autorizada em `assets/logo/` e atualize os dois caminhos no HTML.
6. As fotografias fornecidas para a unidade foram otimizadas em WebP e estão em `assets/images/`.

O formulário não simula backend: ele valida os dados e, quando o link for configurado, monta a mensagem para envio pelo WhatsApp.
